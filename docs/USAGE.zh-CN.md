## 1. Codex

安装后，把下面内容发送到 Codex 的对话输入框：

```text
$yila-clear-writing 修改下面的段落，删去重复退让，写清观点和依据。

正文：[粘贴正文]
读者与用途：[填写]
支持材料：[粘贴事实、数据或来源]
输出：先给可直接使用的正文，再列重要修改理由。
```

## 2. Claude Code

```text
/yila-clear-writing 修改下面的段落，删去重复退让，写清观点和依据。

正文：[粘贴正文]
读者与用途：[填写]
支持材料：[粘贴事实、数据或来源]
输出：先给可直接使用的正文，再列重要修改理由。
```

## 3. 网页对话：ChatGPT / Claude / Gemini / Yila

打开[网页通用指令](WEB-PROMPT.zh-CN.md)，复制其中的完整指令到新对话，再填写正文和支持材料。也可以把该文件作为附件，与本次任务一起发送。

需要特定场景时，打开[分类目录](library/zh/index.md)，复制相应模板，替换其中的材料即可。

## 4. 选择 Skill 工作方式

在调用后说明本次任务：

| 工作方式 | 发送什么 | 得到什么 |
|---|---|---|
| 诊断 | 逐句标注哪些话推进论证，哪些话只是在预先退让；给出依据。 | 原句、作用、处理建议和理由 |
| 改写 | 在保留事实与语气的基础上直接修改，优先做必要改动。 | 可直接使用的正文 |
| 起草 | 根据下面事实写一段面向指定读者的文字。 | 围绕任务组织的新稿 |
| 推荐模板 | 找一套用于延期说明的提示词，给出编号、完整模板与相关案例。 | 可复制模板和案例入口 |

例如，在 Codex 中只检查文字而暂不重写：

```text
$yila-clear-writing 诊断下面段落。
按“原句—信息作用—保留或修改—理由”输出。
正文：[粘贴正文]
支持材料：[粘贴材料]
```

## 5. 控制输出

把需要的形式加在任务末尾：

- **直接替换**：只输出修改后的正文。
- **逐项核对**：给出原句、改写和理由，单独列出需要补充依据的地方。
- **保持文风**：保留作者的语气和术语，优先做最小改动。
- **跨语言**：输出英文，保持原文事实与结论强度。
- **控制篇幅**：压缩到 200 字以内，保留关键事实和行动。

## 6. 一个可以直接练习的例子

```text
$yila-clear-writing 改写下面的项目汇报，只输出正文。

已确认事实：页面开发完成；接口权限待开通；联调未开始。
会议确定：可联调版本从周二调整为周四交付，请项目经理今天协调权限。
原稿：整体推进顺利，我们一直非常努力。由于情况复杂，后续可能稍有延后，望理解。
```

改写示例：

> 页面开发已完成，接口权限待开通，联调未开始。可联调版本由周二调整为周四交付，请项目经理今天协调接口权限。

Claude Code 中将首行调用名称换成 `/yila-clear-writing`；网页对话中先提供[通用指令](WEB-PROMPT.zh-CN.md)，再发送该任务。
