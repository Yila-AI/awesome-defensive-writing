# Frequently asked questions

[Home](../README.md) · [简体中文](FAQ.zh-CN.md)

## Should I copy a prompt or install the skill?

Copy a [template](library/en/index.md) for an occasional edit. Install the skill for repeat tasks. In a web conversation, use the [standalone instructions](WEB-PROMPT.md).

## How do I choose a template?

Start with the deliverable: a paper, proposal, email, update or technical explanation. Categories organize concrete tasks with explicit inputs, outputs and expandable cases. Start with [DW-001 sentence-level diagnosis](library/en/clarity.md#dw-001) when unsure.

## Should every “may,” “cannot” or “only if” be removed?

Check its function. “Estimated for Thursday” marks a forecast; “open only after disconnecting power” states a prerequisite. Keep meaningful conditions next to the relevant claim and remove repetition that adds no information.

## How do I preserve my voice?

Add: “Keep the author's voice, terminology and normal courtesy; make minimal edits.” Add “return clean copy only” when you want replacement text.

## What should I check if the skill does not appear?

Check for `skills/yila-clear-writing/SKILL.md` and retain the `references` folder. Confirm that this is a directory your client reads, reopen the client and follow the [usage guide](USAGE.md). See [installation and updates](INSTALL.md).

## How do I contribute?

Provide the task, complete input, prompt, revision, reasoning and source in the [contribution format](../CONTRIBUTING.md). A meaning-changing edit is also a useful correction case.
